# AURA OS — The AI Company Operating System

[![Vercel Deployment](https://img.shields.io/badge/Vercel-Deployed-success?style=for-the-badge&logo=vercel)](https://aura-os.vercel.app)
[![GitHub](https://img.shields.io/badge/GitHub-AuraOs1%2Faura--os-blue?style=for-the-badge&logo=github)](https://github.com/AuraOs1/aura-os)

AURA OS is an autonomous AI Operating System designed for multi-brand orchestration, C-Suite agent execution, semantic memory recall, and enterprise security.

## Core Features
- **Executive Council**: Chief of Staff Aura, CEO Sarah, CTO Alex, CMO Maya, COO David, CFO Ellen.
- **Voice Input & Output**: Real Web Speech API microphone dictation and spoken SpeechSynthesis responses.
- **Multi-Brand Workspace**: Switch between ZenBudget, AURA OS, LeadFlow AI, and CS Design in 1 click.
- **Autonomous GitHub Auto-Sync**: Agents auto-commit and push code updates to `AuraOs1/aura-os`.
